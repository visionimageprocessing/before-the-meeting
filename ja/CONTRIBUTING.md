# 追加のしかた

[English](../en/CONTRIBUTING.md) | [简体中文](../cn/CONTRIBUTING.md) | [トップ](../README.md)

先生ごとのバージョンを追加できます。送っていただくのは、**mdファイル1つだけ**です。READMEの一覧の更新など、ほかのことは管理者が行います。

このリポジトリには直接書き込めないので、自分のコピー（**フォーク**）にファイルを追加し、**プルリクエスト**で送ってください。GitHubのアカウントは必要ですが、コマンドラインは不要です。ブラウザだけでできます。

## 手順

1. このリポジトリを開き、**Fork** を押して、自分のコピーを作ります。
2. 自分のフォークで、言語のフォルダ（`ja/`、`en/`、`cn/`）を開きます。**Add file** → **Create new file**（または **Upload files**）で、`before-<id>.md` を追加します。
3. 保存（コミット）します。続けて、フォークのページで **Contribute** → **Open pull request** を押します。
4. プルリクエストのメッセージに、次の3行を書いてください。名前は、どの言語でも使えるように、アルファベットで書いてください。
   ```
   Contributor name: Given-name Family-name
   URL: https://自分の個人ページ
   Original language: ja
   ```
   `URL` は、個人のウェブページです（ない場合は、研究室や大学のページ）。`Original language` は、指示書を最初に書いた言語です。
5. 管理者が確認して取り込み、出典の表記と一覧への追加も行います。

コマンドラインを使う場合も流れは同じです（フォーク、クローン、ブランチ作成、コミット、プッシュ、プルリクエスト）。

## Issue（質問・報告）

新しいファイルの追加以外のことは、Issueに書いてください。

- 指示書の間違いや問題（どのファイルか書いてください。例：`ja/before-mtanaka.md`）
- 翻訳の間違い
- 新しい言語の追加の希望
- 使い方についての質問

何が起きたか、どのAI（ClaudeかChatGPT）を使ったかも書いてください。未発表のデータ、個人情報、学生の名前は書かないでください。

## ルール

- **ファイル名：** `before-<id>.md`。`<id>` は、名前の頭文字と姓を小文字でつなげたもの（例：`before-mtanaka.md`）。
- **1ファイルでかまいません：** 1言語だけで大丈夫です。まだフォルダがない言語の場合は、短いコード（例：`ko`、`fr`）の新しいフォルダにファイルを置き、プルリクエストにその旨を書いてください。残りの準備は管理者が行います。
- **目的を保つ：** 学生が自分の言葉で説明すること、AIが一度に一つだけ質問すること、評価ではなく理解が目的であること。それ以外は、各研究室に合わせて変えてください。
- **機密を入れない：** 未発表のデータ、個人情報、学生の名前は書かないでください。
- **既存のファイル：** 修正するのは、そのファイルの作者だけです。他の人のファイルに問題を見つけたら、Issueで知らせてください。
- **GitHubのアカウントがない場合：** 管理者（トップの `README.md` を参照）に、ファイルと、名前（アルファベット）、URL、元の言語を送ってください。
