# 如何添加

[日本語](../ja/CONTRIBUTING.md) | [English](../en/CONTRIBUTING.md) | [首页](../README.md)

你可以添加适合自己研究室的版本。需要提交的只有**一个 md 文件**。更新 README 中的列表等其他工作，由管理员负责。

由于无法直接向本仓库写入，请把文件添加到你自己的副本（**Fork**）中，并通过 **Pull Request** 提交。需要有 GitHub 账号，但不需要使用命令行，只用浏览器就可以完成。

## 步骤

1. 打开本仓库，点击 **Fork**，创建你自己的副本。
2. 在你自己的 Fork 中，打开语言文件夹（`ja/`、`en/`、`cn/`）。点击 **Add file** → **Create new file**（或 **Upload files**），添加 `before-<id>.md`。
3. 保存（提交）。接着，在 Fork 的页面上点击 **Contribute** → **Open pull request**。
4. 在 Pull Request 的说明中写上下面三行。为了便于在任何语言中使用，姓名请用字母书写。
   ```
   Contributor name: Given-name Family-name
   URL: https://你的个人主页
   Original language: cn
   ```
   `URL` 是你的个人网页（如果没有，请填写研究室或大学的页面）。`Original language` 是你最初编写指令书时所用的语言。
5. 管理员会进行确认并合并，同时添加出处标注和列表中的条目。

使用命令行时，流程也是一样的（Fork、clone、创建分支、提交、push、Pull Request）。

## Issue（提问・报告）

除添加新文件之外的事项，请写在 Issue 中。

- 指令书中的错误或问题（请写明是哪个文件。例如：`cn/before-mtanaka.md`）
- 翻译错误
- 希望添加新的语言
- 关于使用方法的问题

请同时写明发生了什么，以及使用的是哪个 AI（Claude 还是 ChatGPT）。请不要写入未发表的数据、个人信息和学生的姓名。

## 规则

- **文件名：** `before-<id>.md`。`<id>` 是名字的首字母与姓氏连在一起，全部小写（例如：`before-mtanaka.md`）。
- **只提交一个文件即可：** 只提供一种语言也可以。如果某种语言还没有对应的文件夹，请将文件放在以简短代码命名的新文件夹中（例如：`ko`、`fr`），并在 Pull Request 中说明。其余的准备工作由管理员完成。
- **保持目的不变：** 学生用自己的话说明；AI 一次只问一个问题；目的是理解，而不是评价。除此之外，可以根据各研究室的情况自行调整。
- **不要放入机密信息：** 请不要写入未发表的数据、个人信息和学生的姓名。
- **已有的文件：** 只有该文件的作者才可以修改。如果发现他人文件中的问题，请通过 Issue 告知。
- **没有 GitHub 账号时：** 请把文件、姓名（字母）、URL 和原始语言发送给管理员（请参阅首页的 `README.md`）。
