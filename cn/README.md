# 48h Before the Meeting — 简体中文

[日本語](../ja/README.md) | [English](../en/README.md) | [首页](../README.md)

这是一份指令书，帮助你在进度汇报会议（Meeting）之前与 AI 进行讨论（壁打ち），从而能够用自己的话说明自己研究的算法和代码。

## 指令书一览

请选择你的指导教师所编写的版本。如果指导教师没有编写，使用哪一份都可以。请将你所使用的版本告知指导教师。

## 什么时候做

请在**会议开始前 48 小时之前、最晚也要在 24 小时之前**完成这次对话。资料也请在此之前准备好。
如果在临近会议时才做，就没有时间进行必要的修改，也来不及加深理解。
AI 会帮你找出理解还不够深入的地方。对话结束之后的时间，正是用来加深理解的。

## 需要准备的东西

- Claude 或 ChatGPT 等服务的账号
- 研究进展资料（幻灯片、笔记）
- （视需要）代码

## 在 Claude 中的使用方法

1. 在 Claude 中新建一个**项目（Project）**。
2. 打开项目的**指令（Instructions）**，粘贴指令书的内容。请不要带上代码块的围栏（```），直接粘贴文字本身。
3. 在项目中开始一个新的对话，附上资料和代码。
4. 发送“请开始”之类的消息，然后依次回答问题。

## 在 ChatGPT 中的使用方法

1. 在 ChatGPT 中新建一个**项目（Project）**。
2. 在项目的**指令（Instructions）**中粘贴指令书的内容（不要带上代码块的围栏）。
3. 在项目中开始一个新的对话，附上资料和代码。
4. 发送“请开始”之类的消息，然后依次回答问题。

## 无法使用项目功能时

在新对话的开头粘贴指令书的全文，并在同一条消息中附上资料和代码。

## 如何提供代码

**聊天（Claude、ChatGPT）：** 附上主要的文件。

**编程工具（Codex、VS Code 扩展、Claude Code 等）：** 打开代码仓库，在新会话的第一条消息中粘贴指令书。AI 会自己读取代码，所以不需要附件。请告诉 AI 资料所在的位置（例如：“幻灯片在 docs/progress.pdf”）。请不要把指令书放在 `AGENTS.md` 或 `CLAUDE.md` 中，否则每次日常开发都会变成讨论模式。

**在这次对话中，不会修改代码。** AI 只负责阅读和提问。即使工具提议编辑文件，也请拒绝。

## 使用小技巧

- 请不要看资料，也不要去问其他 AI，用自己的话来回答。目的不是答对，而是找出自己还不明白的地方。
- 回答“不知道”也没关系。AI 会给出提示。
- 想结束时，请告诉 AI“我想先到这里”。AI 会整理出已经明白的内容、仍然模糊的内容，以及适合向指导教师请教的问题。请把这份整理带到会议上。
- 未发表的数据和代码是否可以交给外部 AI 服务，请遵守研究室的规定。
- Claude 和 ChatGPT 的菜单名称可能会变化。如果显示不同，请查找项目的指令（自定义指令）设置。
